# Check Stock - Aplicación Híbrida SPA

Aplicación móvil híbrida de control y gestión de inventario offline-first, desarrollada con **Vanilla JavaScript**, preprocesador **SASS** y empaquetada mediante **Vite**.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5 / Vanilla JavaScript (ES6 Modules):** Lógica de enrutamiento SPA y manipulación del DOM.
* **SASS (SCSS):** Estilos modulares organizados en clases parciales (`_variables.scss`, `_navbar.scss`, etc.).
* **Vite:** Bundler de desarrollo y optimizador de código para producción.
* **LocalStorage:** Persistencia de datos 100% local para garantizar funcionamiento offline sin conexión a internet.
